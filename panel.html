Welcome to the CRM Sidekick!

Before you get started, here’s a quick overview of what this tool is and how it can help you.

CRM Sidekick is a browser extension designed to streamline your daily tasks with a set of helpful, easy-to-use tools. While it’s not a full automation platform like Power Automate and still requires some user interaction, it removes many of the time-consuming steps you deal with every day.

Instead of one-click check-ins, CRM Sidekick guides you through the process and takes care of repetitive work such as:

  • Naming and zipping files
  • Formatting and submitting your CRM notes
  • Eliminating common manual entry tasks

If you have any questions or need help, feel free to reach out to Jordan.

Update notes

What’s new since version 1.0.6.

Version 1.0.7 highlights
  • Updated wording of instructions.
  • Added a name refresh for the QA form, so logging in to CRM does not leave the name blank.
  • Added a catch for .wf lamp files that were not triggering Saltillo in the naming convention.
  • Updated NFL themes that were hard to read.
  • Added a custom theme builder suite that allows users to create and share themes they made with others via a key generation method.
  • Updated the Talkpad Prep checklist so users can customize their workflow and see categorized steps.
  • Fixed an issue where Evo cameras were not being added to the check-in form.
  • Introduced an LTL Update beta with core functionality.
  • Enhanced the CRM inventory search script to handle multiple cameras.
  • Integrated the CRM navigator into the landing page instead of a separate tool page.
  • Overhauled the Talkpad Prep tool for a smoother workflow.
  • Added a slider to increase or decrease profile image size.
  • Enabled image toggles in the custom theme builder suite for more control.
